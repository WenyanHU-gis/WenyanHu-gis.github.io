BioCondition Score Calculation Python Tool

PythonArcPyArcGIS ProEcologySpatial Analysis

The Landscape Attribute Assessment Tool (ArcPy) is a ready-to-use Python tool packaged as an ArcGIS Pro Python Toolbox (.pyt). It automates the calculation of BioCondition (2015) landscape-scale metrics for fragmented subregions, assessing biodiversity parameters across size, connectivity, and environmental context.

Key Features & Workflow:

  • Data Input & Preparation: Integrates field-verified Regional Ecosystem (RE) data with Queensland Globe spatial datasets, clipping, merging, and harmonising vegetation classes seamlessly.
  • ArcPy Analysis Engine: Delineates contiguous remnant vegetation patches and automates metrics calculation for each patch based on official BioCondition methodology.
  • Core Landscape Attributes Evaluated:
    • Size of Patch: Evaluates area of contiguous remnant vegetation (ha) to measure habitat value.
    • Connectivity: Calculates distance to nearest native vegetation patches and surrounding landscape connections.
    • Context: Computes the proportion of native vegetation within a specified radius (e.g., 1 km).
  • ArcGIS Pro Tool Integration: Built as a Python Toolbox (.pyt) with a user-friendly parameter interface for direct execution within ArcGIS Pro.
  • Spatial & Tabular Outputs: Generates structured file geodatabase (.gdb) tables and GIS vector layers ready for cartographic mapping, reporting, and statutory environmental assessments.

Impact & Value:

This tool streamlines environmental impact assessments and conservation planning in Queensland by replacing manual GIS steps with a repeatable, automated ArcPy script. It enables ecological consultants and spatial analysts to evaluate fragmented subregion metrics rapidly with high consistency.
